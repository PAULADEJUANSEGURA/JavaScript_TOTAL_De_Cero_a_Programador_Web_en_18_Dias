La etiqueta <p> se utiliza para crear párrafos de texto.

La etiqueta <br> se utiliza para hacer un salto de línea.


También puedes utilizar la etiqueta <pre> para mantener el formato del texto tal como lo escribes, incluyendo los saltos de línea y los espacios en blanco:

        Hola, mundo!
        Hola, Soy Paula.
        Bienvenidos a mi sitio web.
